# Performance Results

This directory is reserved for timestamped, unmodified Locust CSV/HTML output
and raw measurements. Phase 5 did not execute a load test because the API and
frontend were unavailable and the configured Qdrant target is external.
Consequently, there are no load-test result files and no before/after
performance claims.

Do not overwrite historical results. Use a unique run stem as shown in
[`../README.md`](../README.md).
